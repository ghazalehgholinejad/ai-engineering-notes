# دفترچه یادگیری مهندسی هوش مصنوعی

یادداشت‌های فارسی غزاله قلی‌نژاد برای یادگیری و مرور مفاهیم ارتباطات نرم‌افزاری، MCP، جست‌وجوی برداری و RAG. هدف این دفترچه این است که هر مفهوم را با زبان ساده، مثال و سؤال مرور بتوانم دوباره بخوانم و به زبان خودم توضیح بدهم.

این مخزن **جزوهٔ آموزشی در حال رشد** است؛ فهرست پروژه‌های انجام‌شده یا گزارش تجربهٔ عملی تأییدشده نیست. مثال‌ها ساختگی و مستقل از اطلاعات محل کار هستند.

برای خواندن نیازی به نصب چیزی نیست؛ روی عنوان جزوه کلیک کن. در هر صفحه بخش‌ها، مثال‌ها و پاسخ سؤال‌های مرور آمده‌اند. هنگام خواندن متن فارسی و کد انگلیسی، کدها در بلوک جدا نمایش داده می‌شوند.

## روش استفاده

۱. یک درس کوتاه بخوان و مفهوم را بدون نگاه کردن با مثال توضیح بده.
۲. به سؤال مرور جواب بده؛ بعد پاسخ پیشنهادی را باز کن.
۳. اگر چیزی را واقعاً اجرا کردی، محیط و نتیجه را در دفتر مرور ثبت کن. «خواندم» با «اجرا کردم» یکسان نیست.
۴. برای موضوع بعدی از قالب آماده یک کپی بساز؛ اسم سرویس، مسئله، مثال و منبع را بنویس.

## اجرای تنها تمرین بدون وابستگی

```bash
python3 examples/vectors/cosine_demo.py
```

این برنامه فقط سه بردار **دستی و آموزشی** را مقایسه می‌کند؛ مدل embedding یا دیتابیس راه‌اندازی نمی‌کند. برای شکل واقعی API و SQL، [کارگاه](notes/vector-databases/practice.md) را بخوان.

## منابع و نگهداری

جزوهٔ MCP از فایل Word ارائه‌شده تبدیل شده؛ نسخهٔ Word محلی تغییر نکرده و فراداده‌های آن در این مخزن منتشر نشده‌اند. جزوهٔ برداری به زبان ساده و با مثال‌های تازه تدوین شده و منبع رسمی هر بخش کنار همان بخش آمده است. تاریخ بررسی منابع جزوهٔ جدید: **۱۰ اکتبر ۲۰۲۶**. رفتار APIها به نسخه وابسته است؛ پیش از استفاده در پروژهٔ واقعی مستندات نسخهٔ نصب‌شده را بخوان.
